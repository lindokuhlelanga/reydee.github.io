# YouTube UI Clone

A front-end practice project recreating the layout of the YouTube desktop interface using **HTML and CSS**.

## Purpose

This project was built as a learning exercise in:

- semantic HTML structure;
- CSS layout and positioning;
- reusable page sections;
- responsive interface styling;
- navigation, sidebar and card-based UI patterns.

## Technologies

- HTML5
- CSS3
